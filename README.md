# Kanak Bari – Portfolio (React + Vite)

## Run locally
    npm install
    npm run dev

## Build for deployment
    npm run build      # output in /dist (deploy to Vercel, Netlify, GitHub Pages)

## Customize
- Content (links, skills, jobs, projects): `src/data.js`
- Colors, fonts, animation: `src/styles.css` (tokens at the top, under `:root`)
- Replace the `#` placeholders for LinkedIn, GitHub and project Live/GitHub links in `src/data.js`.
